# 최종 제한 수정 — Gemini 4 담당

앞 구현·1차 재작업은 Gemini 4 Argon High가 완료했고 Codex 검토에서 아래 두 실제 문제를 찾았다. 수정 허용 파일은 scripts/prepare-case-assets.py 와 scripts/check-seo.py 두 개뿐이다. run_command, Git, 다른에이전트, 커밋/푸시/배포 금지. 네이티브 파일 편집만 한다. 사이트본문·가격을 검사에 맞춰 바꾸지 않는다.

1. 청운재 장부 원본의 실제 크기는2390x755이다. Codex가view_image의축소미리보기2048x647을원본으로오인해crop(0,0,2048,340)을지시했고, 그결과원본의오른쪽항목과헤더아래부분이잘렸다. 이지시좌표를그대로쓰지말고 원본전체폭을2048x647로비율축소한후 그파생이미지의(0,0,2048,340)을발췌하여야한다. 즉 청운재sheet에한해서wholeRGB원본을2048x647로resize한뒤현재crop적용. 결과최종2048x340유지, 날짜별데이터행/오픈일행없음, 전체열과하위조중석식항목온전히보존. 타사진·원본파일은변경하지않는다. 실제픽셀내용을다른값으로쓰거나가상표를만들지않는다. Codex가실행·시각검수한다.

2. python -S scripts/check-seo.py 와 python scripts/check-seo.py --check-images 가16페이지일반검사후 cases.html의1만원금칙어로실패했다. 허브의월1만원은price.html과일치하는실제맞춤리포트부가서비스요금이며정상정보다. 이를삭제하거나표기만바꾸어검사를피하지않는다. 범용 CASE_FORBIDDEN_TERMS 에개별금액/숫자/미정/부정/누수같은일반단어를넣는방식은올바른설명이나관련링크를오탐한다. 콘텐츠의사실범위와문체는이미Codex+Claude가검토하므로이검사목록을필요최소한으로단순화하라. 알려진잘못된명칭(한전청운제/총재), 불가능한2026-09-31, 실제미확정도입일을단정하는오픈일/09/30 등이번범위의명백한오류와정확한전체허위보장문구정도만남긴다. 정상금액/일반단어/151·131수치정규식은제거한다. 기존모든SEO/구조/영상ID/링크/sitemap/이미지/FAQ/폼/브랜드검사는보존한다. 표준라이브러리기본실행과명시적Pillow옵션을유지한다.

두파일만읽고실제수정하라. 정확한수정내용만짧게보고하고명령실행·테스트는Codex에게맡긴다.
