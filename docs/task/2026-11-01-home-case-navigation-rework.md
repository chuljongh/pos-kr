## 반드시 이 세 가지만 수정

1. index.html 리드의 '영상을 끝까지 보지 않아도...'는 고객 운영 목적 안내로 교체: '회사별 정산, 사전 식사 신청, 식사 대상자 관리 중 우리 식당과 가까운 실제 운영 사례를 확인하세요.' 메인 목적은 사례 선택이며 내부 구현·탐색 이유를 고객에게 설명하지 않는다.
2. 청운재 배지 '기숙사 전용 구내식당'은 '기숙사 · 협력업체 구내식당'으로 변경. 허용된 협력업체도 식사하므로 전용이라는 표현을 피한다.
3. cases/kcci-gwangju.html에서 새 포스터 img만 object-position:right center로 맞춘다. Codex가 실제 화면과 원본을 대조하니 현재 center cover는 양 끝 태블릿을 모두 일부 잘라 보인다. 오른쪽 기준이면 원본 오른쪽 태블릿이 온전히 보인다(3:4사진을9:16틀로 cover). 다른 그림/플레이어/컨테이너/iframe CSS는 바꾸지 않는다. CSS 표시 조정이며 실제 이미지 파일은 바꾸지 않는다.

- 네이티브 편집 도구만 사용. 명령/Git/배포/설정변경 금지. 수정2파일 이외 편집 금지. 마지막으로 실제 읽기검토하여 세 수정과 링크·가독성·SEO/GEO/AEO·기존보존 조건을 최종 자체 검토하고 결과를 답한다. 브라우저를 직접 실행했다고 주장하지 말고 Codex가 보고한 검사와 구분한다.
