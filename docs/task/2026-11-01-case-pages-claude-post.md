## P0 — 게시 전 반드시 수정

1. **청운재 도입일 사실상 노출** (`cases/cheongunjae.html` 집계표 설명)
   - 본문에 "09/30(수) 오픈일"이 적혀 있어, 확인 중인 도입일을 9/30으로 확정해 공개하는 셈입니다.
   - 본문에서 날짜와 "오픈일"을 삭제하고 "특정 일자의 끼니 합산 기록 예시"로만 표현하십시오.
   - 이미지 안에도 날짜·오픈일이 보이면 해당 영역을 가리거나 자르고, 날짜가 확정된 뒤 복원하는 것을 권합니다.

## P1 — 인터뷰에서 확인하지 않은 사실·성능·수식어

2. **광주 FAQ "400명 규모가 몰려도 스캔이 원활한가요?" 삭제**
   - 피크 처리 성능은 확인한 사실이 아닙니다.
   - 400명은 하루 평균 이용 규모인데, 배식 시간 동시 인원처럼 읽힙니다.
3. **광주 사진 설명 "대기 줄이 밀리지 않도록 2대를 배치"**
   - 배치 목적과 대기 효과는 확인되지 않았습니다. "배식 공간 앞 태블릿 스캐너"로만 쓰십시오.
4. **설치 대수 단정**
   - 청운재 "거치형 태블릿 1대", 광주 "태블릿 2대"(허브 표와 카드 포함)는 인터뷰에서 확인한 설치 총대수가 아닙니다.
   - 사진에 보이는 사실만 남기려면 "사진 속 2대"처럼 표현하고, 그렇지 않으면 대수를 빼십시오.
5. **청구 주기 추정**
   - 광주 도입 전 설명의 "월말에 과정별로 나누어 청구"는 청구 기준을 확인하지 않은 내용입니다.
   - "과정별로 구분해 청구해야 해"로 고치십시오.
6. **청운재 집계표 '외부인 식수' 해석**
   - 이 열이 "협력업체 근무자 등 비기숙사 등록 대상"이라는 해석은 장부 항목 정의를 확인한 것이 아닙니다(본문과 FAQ 양쪽).
   - 운영사 확인 전까지 해당 FAQ와 설명을 빼거나 "운영사 설명에 따르면"으로 출처를 밝히십시오. 표가 보이므로 질문이 나올 수는 있으니, 사용자에게 확인하는 편이 낫습니다.
7. **단정·절대 표현**
   - 청운재 "종이 쿠폰을 세는 작업이 사라졌습니다" → "줄었습니다"
   - 두리미가 "정확히 대조", "투명하게" 삭제
   - 두리미가 "수기 기재 착오" → "차이"(원인을 단정하지 않음)
   - 광주 "정산 확인 업무가 간소화되었습니다" → "구분해 확인할 수 있습니다"
   - 광주 "계획적인 식수 신청을 유도" 삭제
8. **확인하지 않은 세부 묘사**
   - 청운재: "매일 사내 보고에 쓰는", "매 끼니가 끝난 뒤"
   - 광주: "외부 기관·기업의" 위탁, 영상 설명의 "점심·저녁 시간 운영 장면"(영상으로 확인되지 않았다면)
   - 각각 삭제하거나 인터뷰 표현으로 되돌리십시오.
9. **사례와 일반 기능·요금 혼동**
   - 허브 FAQ의 "Plus 이상 포함, Super·Pro 부가 서비스"는 price.html의 현재 문구와 일치하는지 대조하십시오.
   - 문단은 "청운재 사례"와 "요금 안내"로 나누십시오.
   - 허브 FAQ "매장 PC를 따로 설치했나요? 아닙니다"는 엑셀 다운로드용 PC 사용과 혼동될 수 있습니다. "스캐너로 태블릿·스마트폰을 사용"으로 표현을 좁히십시오.

## 권고 (선택)

- **두리미가 "10,000원은 촬영 당시 설정 예시"**: 금액 해석을 단정하지 말고 "화면 금액은 촬영 당시 표시"까지만 쓰거나 언급하지 마십시오.
- **스키마**: 사례 페이지의 VideoObject가 index와 같은 @id를 쓰면서 isPartOf를 사례 Article로 지정해, 그래프를 합치면 소속이 충돌합니다.
  - 사례 페이지에서는 Article.video에 @id 참조만 남기고 VideoObject 본문은 빼거나, isPartOf만 제거하십시오.
  - `#giftcoin`, `#website` @id가 index에 실제로 정의되어 있는지 확인하십시오.
- **JS**: Ctrl·Shift·Meta 클릭이나 휠 클릭은 새 탭으로 열리게 두십시오(`if (e.button||e.ctrlKey||e.metaKey||e.shiftKey) return;`).
  - 클릭으로 만든 iframe의 `loading=lazy`는 불필요합니다.
  - 트리거는 `<a href=watch>`를 유지하고 포스터 img의 alt를 확인하십시오.
- **CSS 중복**: Pretendard를 preload와 stylesheet로 이중 로드합니다. 기존 페이지 방식과 같다면 그대로 두어도 됩니다.
- **check-seo 복잡도**
  - 표준 라이브러리 전용 스크립트에 PIL 의존이 생겼습니다. PIL이 없는 환경에서는 전체 검사가 실패하므로, import 실패 시 이미지 검사만 건너뛰거나 별도 스크립트로 분리하십시오.
  - 금칙어를 원문 HTML 전체에 부분 문자열로 검사해 오탐이 납니다. '151', '131'은 경로·크기 값과, '0%'는 정상 수치와, '부정'은 '부정확'·가이드 링크 문구와 겹칩니다. 반면 '10,000원'은 통과합니다. 화면 텍스트만 검사하고 숫자는 단어 경계로 매칭하십시오.
  - '일부 회사 단위 수기 기록' 하드코딩 검사는 문구 수정 시 깨지므로 제거를 권합니다.
- **index 변경**: VideoObject uploadDate의 시간대 변경은 같은 시각이라 무해합니다. 다만 사례 검사 일치를 위한 기존 데이터 수정이므로 작업 기록에 남기십시오.

- 고객 직접 인용, 별점, Review·FAQPage·LocalBusiness 스키마가 없습니다.

- 인원 규모마다 "운영사 설명"과 "합산 식수 ≠ 고유 인원" 안내가 있습니다.

- 운영사 확인 기준일(2026-11-01)을 공개했습니다.
