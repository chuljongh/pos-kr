# 장부·QR 메인 이미지 교체

- 2026-11-05 / Codex. 회사별 장부를 스마트폰·스캐너 뒤에 배치한 승인 합성본으로 표지를 교체한다. 이미지 구성과 사이트 레이아웃은 추가 수정하지 않는다.
- 승인 원본은 mainimg.png(1774×887)로 저장하고, 웹용 mainimg.jpg/mainimg.webp(1600×800)와 mainimg-800.webp(800×400)를 제공한다. 화면에서는 최적화된 WebP/JPEG를 사용한다.
- 기존 mainImg.jpg/mainImg.webp/mainImg-800.webp는 각각 mainimg_old.jpg/mainimg_old.webp/mainimg_old-800.webp로 보관했다. Git 기준 원본과 바이트 및 SHA256이 일치한다.
- 메인·제안서·브로셔의 이미지 참조와 모바일 srcset·대표 이미지 스키마를 새 소문자 파일명으로 맞추고, 메인 CSS 링크에 버전20261105를 붙였다. 대체 텍스트에는 뒤편의 회사별 장부를 추가했다. 제목·가격·폼·분석 코드·공유용 OG 이미지·카페 콘텐츠는 유지했다.
- 실제 Gemini4가 최소 참조 변경과 변환 스크립트를 작성했으며, Codex가 스크립트를 검토·실행해 이미지를 준비했다. 실제 Claude 전후 검토의 배포 전 조건은 Codex의 원문 대조·저장소 전체 검색·이미지/화면 검증으로 확인했다. 일회성 준비 스크립트는 배포에서 제외한다.
