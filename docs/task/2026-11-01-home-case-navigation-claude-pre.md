# 사전 검토: 홈페이지 사례 선택 버튼·광주 쇼츠 비율

## P1 (구현 시 반드시 반영)

**1. 카드 문구의 근거 대조 (사실 단정)**
- 다음 세 표현은 각 상세 페이지에 실제로 있는 문장에서만 가져와야 합니다.
  - "다음 주 끼니 신청"
  - "영양사의 발주·조리 준비에 활용"
  - "기숙사생·허용된 협력업체 구분"
- 상세 페이지에 없는 표현이면 빼야 합니다. Codex는 카드 문구와 상세 본문을 1:1로 대조합니다.
- 카드 제목·설명에 "함바", "100%", "보안"이 없는지 문자열 검사로 확인합니다.

**2. GA 이벤트 함정 (메모리에 기록된 기존 문제)**
- GTM 트리거는 `cta_click_*` 접두사가 붙은 "클릭된 요소 자체"만 잡습니다.
- 따라서 `data-ga-event`는 반드시 `<a>`에 둡니다.
- `<a>` 안에 아이콘·span·img를 넣으면 그 부분을 클릭했을 때 이벤트가 빠집니다. 링크는 텍스트만 두거나 자식 요소에 `pointer-events:none`을 줍니다.
- 카드 전체를 감싸는 링크와 버튼 링크를 중첩하지 않습니다.

**3. 접근성: 보이는 문구와 aria-label 일치 (WCAG 2.5.3)**
- aria-label에 보이는 문구가 그대로 들어가야 합니다. 예: 보이는 문구 "도입 사례 보기" → aria-label "두리미가 솥밥 도입 사례 보기".
- 또는 aria-label 대신 sr-only span으로 현장명을 보충하는 방법이 더 단순합니다. 단, 2번 GA 조건과 충돌하므로 둘 중 하나를 골라 지시하세요.

**4. 제목 계층**
- `#how-to`의 기존 h2 아래라면 사례 영역 제목은 h3, 카드 제목은 h4입니다.
- 별도 h2로 만들면 `#how-to` 밖 구조와 맞는지 확인합니다.
- 단계를 건너뛰지 않습니다.

**5. 광주 포스터 비율과 CLS**
- `kcci-gwangju-scanners.webp`는 3:4이고 프레임은 9:16입니다.
- 비율은 이미지가 아니라 컨테이너(`aspect-ratio:9/16`)가 정해야 합니다.
- img는 `width=900 height=1200`과 `object-fit:cover`로 두고, 좌우 약 25%가 잘리므로 `object-position`으로 주요 피사체가 남는지 눈으로 확인합니다.
- "확대·크롭 금지"는 iframe(영상)에만 해당하고, 포스터 사진 cover 크롭은 허용된다고 지시서에 명시하면 Gemini의 해석 충돌을 막습니다.

**6. 360px 넘침**
- 플레이어는 `width:100%; max-width:340px`로 지정합니다.
- 고정 340px에 패딩이 더해지면 360px 화면에서 가로 넘침이 생길 수 있습니다.

**7. 모바일 길이**
- 1열에서 사진 3장이 세로로 쌓이면 영상이 너무 아래로 밀립니다.
- 카드 사진은 낮은 고정 비율(예: 16:9, 높이 약 160–180px 상한)로 제한합니다.
- 세 사례 모두에 맞는 사진이 없으면 셋 다 사진 없이 통일합니다. 한 카드만 사진이 빠지는 것은 금지합니다.

**8. 링크 경로**
- 기존 내부 링크 형식(확장자·끝 슬래시 유무)과 같게 씁니다.
- 두 Vercel 프로젝트 모두에서 `/cases/*`가 200으로 바로 응답하는지 배포 후 확인합니다. 리다이렉트 한 번 거치는 것도 피합니다.

**9. 광주 실영상 육안 확인**
- 클래스를 세로로 바꾼 뒤 iframe 안에 위아래나 좌우 검은 띠가 없는지 확인합니다.
- 띠가 보이면 원본이 가로라는 뜻이니 중단하고 사용자에게 보고합니다.

## 선택 권고
- **링크 문구:** 보이는 문구가 "도입 사례 보기" 3개로 반복되면 SEO·스크린리더 링크 목록에서 약합니다. "두리미가 솥밥 사례 보기"처럼 현장명을 넣으면 3번 문제도 함께 해결됩니다.
- **광주 포스터 alt:** 같은 사진이 상세 페이지 갤러리에도 있다면, 포스터 alt는 "영상 재생: [영상 제목]"으로 구분합니다. 재생 버튼의 접근 가능한 이름에도 영상 제목을 넣습니다.
- **기존 포스터 파일:** `kcci-gwangju-video-poster.webp`가 VideoObject의 `thumbnailUrl`이나 og:image에 쓰이고 있으면 그대로 둡니다(schema 변경 금지 조건). 어디에서도 쓰지 않게 되더라도 삭제하지 말고 보고만 합니다.
- **기존 영상 하단 작은 링크:** 새 "모든 도입 사례 보기" 버튼과 중복되면 하나로 줄여도 됩니다. 이 경우 해당 `data-ga-event` 이름은 유지하거나, 바뀌는 사실을 기록합니다.
