# 사후 검토 (실제 diff 기준)

## 판정
**P0 없음.** 구조·접근성·GA 관례·광주 플레이어 전환은 지시서와 맞습니다. 다만 아래 P1 두 건은 게시 전에 정리해야 합니다. 하나는 문구 정정이고, 다른 하나는 카드 문구가 원문에 실제로 있는지 대조하는 일입니다.

## P1 (게시 전 필수)

1. **'기숙사 전용 구내식당' 배지 → 변경 권고**
   - 같은 카드 설명이 "허용된 협력업체 근무자(선불 이용권)"를 식사 대상으로 명시합니다. 그래서 '전용'은 설명과 모순되고, 협력업체도 식사하는 현장이라는 사실을 가립니다.
   - 대안(새 사실 없음): `기숙사 · 협력업체 구내식당` 또는 `기숙사 구내식당`.

2. **카드 세부 문구의 원문 대조**
   - 지시서와 사전 대조 범위를 넘는 표현이 있습니다. 상세 페이지 본문에 그대로(또는 같은 뜻으로) 있는지 Codex가 확인해야 하고, 없으면 삭제하거나 원문 표현으로 바꿉니다.
   - 두리미가:
     - `서울 서초구`
     - `한식뷔페 · 외식 매장`
     - `문자 QR 카드`
     - `월초 수기 장부 해독 부담`
   - 광주:
     - `교육기관 · 기숙사 급식`
     - **`과정별·기숙·통학별로 정산`** — diff에 보이는 광주 상세 원문은 "과정별·구분별로 나누어 **확인**"입니다. '정산'은 의미가 확대된 표현이므로, 원문에 '정산'이 없으면 "확인"으로 맞춥니다.
   - 청운재:
     - `일일 자동 배포`
     - `선불 이용권`
     - `위탁운영사 맞춤 엑셀 양식`

## '영상을 끝까지 보지 않아도' 판단
**운영 목적 안내로 바꾸는 편이 적절합니다.**

- 이 영역은 영상 그리드보다 **앞**에 있어서, 방문자는 아직 영상을 보지 않은 상태입니다. 문장이 맥락과 어긋납니다.
- 내부 목표 문구("영상을 지나치지 않고도")가 고객 문구로 새어 나온 형태이기도 합니다.
- 예시(기존 사실 범위 내): "회사별 정산, 사전 식사 신청, 식사 대상자 관리 중 우리 식당 고민과 가장 가까운 실제 현장을 선택해 확인하세요."

## 광주 플레이어 확인
- `wide-poster`와 `landscape`를 제거해 `340px 1fr` 그리드와 9:16 프레임으로 복귀했습니다. 원본 1080x1920과 맞습니다.
- iframe에는 크롭·확대 CSS가 없습니다. 영상 ID, href, `data-ga-event`, JS click-to-load도 그대로입니다. 적합합니다.
- 3:4 포스터를 9:16 프레임에 cover로 넣으면 **좌우가 약 25% 잘립니다.** 태블릿 스캐너가 프레임 안에 남는지 실브라우저 육안 확인이 필요합니다. 잘리면 `object-position` 조정 정도만 검토합니다.
- 모바일 340px 상한은 제공된 CSS에 모바일 미디어쿼리가 없어 판단할 수 없습니다. 실브라우저 결과로 확인해야 합니다.
- `kcci-gwangju-video-poster.webp`는 schema·og 등에서 참조될 수 있으므로 파일을 삭제하면 안 됩니다. 이번 diff는 삭제하지 않았습니다.

## 접근성·GA (문제 없음)
- CTA는 순수 텍스트이고 `cta_click_*` 접두사를 씁니다. GTM의 클릭 요소 매칭 조건에 부합합니다.
- aria-label에 보이는 텍스트 "도입 사례 보기"가 포함돼 있어 label-in-name을 충족합니다.
- `#d11927`/흰 글자 대비는 약 5.4:1로 AA를 통과합니다. 버튼 높이 52px 이상, focus-visible이 있습니다.
- 계층은 h3 영역 → h4 카드이고, 중첩 링크가 없습니다.

## 선택 권고
- 카드 제목·리드 문단에 `word-break: keep-all` 추가: 360px에서 한국어 단어 중간 줄바꿈을 막습니다.
- 768px에서는 1열입니다. 지시서상 허용 범위라 유지해도 됩니다.
- 광주 포스터 alt의 "(영상 재생 전 포스터)"는 링크 aria-label에 가려지므로 영향이 없습니다. 그대로 둬도 됩니다.

## 게시 가능 조건
1. P1-1 배지 문구를 수정한다.
2. P1-2 대조 결과를 반영한다. 특히 광주 카드의 '정산'.
3. 리드 문장을 운영 목적 안내로 교체한다(권고 수준이지만 이번 재작업에 포함 권장).
4. 실브라우저 360/390/768/1440에서 아래를 통과한다.
   - 세 카드와 모음 버튼의 이동 경로
   - 가로 넘침 없음
   - 광주 포스터에서 태블릿이 잘리지 않음
   - 클릭 전후 9:16 유지
   - 다른 두 사례와 메인 영상 3개 보존
   - JS 오류 없음
5. 재작업 후 SEO16과 이미지 검사를 재통과하고, 두 파일만 커밋한다.
