## 1. 한 줄 정의

> **"광택이 적은 매트 비닐 피규어(아트토이) 질감의 3D 치비 캐릭터, 약 2.5~3등신, 큰 머리·작은 몸, 검정 단발/긴머리, 동그란 유리알 눈 + 굵은 눈썹, 밝은 웃음, 흰 배경 위 부드러운 스튜디오 조명."**

## 2. 비율·체형 [측정·관찰]

| 항목 | 값 | 비고 |
|---|---|---|
| 등신 | **약 2.5~3등신** | 여학생(서 있음): 머리(머리카락 포함) ≈ 전체 높이 36% / 바리스타: 모자~턱 ≈ 34% |
| 머리 모양 | 가로로 약간 넓은 둥근 사각(쿠션형) | 볼 아래가 통통, 턱선 둥글고 짧음 |
| 목 | 거의 없음 | 머리가 바로 어깨/옷깃 위에 놓임 |
| 몸통 | 짧고 직사각형, 어깨 좁음 | 허리 굴곡 없음 |
| 팔 | 짧고 굵은 원통형, 팔꿈치 표현 약함 | 손은 **주먹 쥔 둥근 덩어리**, 손가락은 얕은 홈으로만 |
| 다리 | 짧고 굵음, 발이 상대적으로 큼 | 신발이 몸 비례보다 크게(안정감) |
| 손 크기 | 얼굴 폭의 약 1/3 | 작고 둥글게 |

## 3. 얼굴 [관찰]

| 부위 | 특징 |
|---|---|
| **눈** | **거의 정원형**(가로:세로 ≈ 1:1.1, 세로로 긴 타원·알약형 아님)의 큰 **유리알 눈**. 한쪽 눈 폭 ≈ 얼굴 폭의 1/5, 두 눈 간격 넓고 얼굴 세로 중앙보다 약간 아래 |
| 눈 색·광택 | 눈 대부분을 **짙은 흑갈색 홍채**가 채움(위쪽 거의 검정 → 아래쪽 약간 따뜻한 진갈색 그라데이션), 반사 광택 있음 |
| 하이라이트 | **큰 흰 원 1개**(위쪽, 조명 방향) + **작은 점 1개**(아래쪽) |
| 흰자·속눈썹 | 흰자는 **바깥 아래 가장자리에 얇은 초승달**로만 보임. 위 가장자리에 **짙은 눈꺼풀/속눈썹 선**, 여성은 바깥 끝이 살짝 올라감 |
| 웃는 눈 | 행복 표정은 **∩ 모양 곡선 눈**(바리스타) — 유리알 눈과 곡선 눈 두 가지 |
| **눈썹** | **굵고 짧은 검정 눈썹**, 안쪽이 내려간 "의욕/결의" 각도(학생·취준생). 이 눈썹이 캐릭터 인상의 핵심 |
| 코 | **아주 작은 둥근 돌기** 또는 생략, 그림자로만 암시 |
| **입** | 크게 벌린 **D자형 웃는 입**, 안쪽 진한 빨강/자주 + 혀 분홍. 윗니는 표현 안 하거나 얇은 흰 띠 |
| 볼 | **연한 복숭아색 블러시** 원형, 경계 흐림 |
| 귀 | 머리카락 옆으로 작게 보이는 반원, 피부색 |
| 피부 질감 | 매끈한 무광~반광, 모공·주름 없음, SSS(서브서피스) 느낌의 부드러운 붉은 기 |

## 4. 머리카락 [관찰]

- 색: 거의 검정에 가까운 **차콜 브라운** (#2F2E33 ~ #443C38) [측정]
- **덩어리(클럼프)로 나뉜 조형** — 실 머리카락이 아니라 3~6개의 큰 덩어리를 깎아 만든 듯한 모양
- 앞머리: 이마를 덮는 **뭉툭한 일자/사선 뱅**, 끝이 뾰족하게 나뉨
- 은은한 **스페큘러 하이라이트 띠**(정수리 쪽 둥근 반사)
- 남성: 짧은 덮는 머리(바가지형 변형), 귀 일부 보임 / 여성: 어깨 아래 긴 생머리 또는 단발+모자

## 7. 렌더링·조명 [관찰]

- **재질**: 매트~세미매트 플라스틱/비닐, 클레이처럼 부드러운 모서리(모든 엣지 라운드)
- **조명**: 좌상단 키라이트 + 넓은 소프트박스 → 부드러운 그라데이션 셰이딩, 강한 반사광 없음
- **그림자**: 발 밑 **짧고 부드러운 접지 그림자(contact shadow)** 하나. 캐스트 섀도는 연하게
- **외곽선 없음**(셀 셰이딩 X). 실루엣은 명암 차이로만 분리
- **카메라**: 단독 컷은 정면~약간 위(15°)에서 내려다봄. 장면 컷은 **아이소메트릭(약 30°)** 블록 위에 배치
- 배경과 분리: 흰/파스텔 배경에서도 떠 보이도록 피부·옷에 약한 림라이트

## 8. 포즈 문법 [관찰]

| 감정 | 포즈 | 사용 예 |
|---|---|---|
| 의욕·응원 | **양주먹 가슴 앞 "화이팅"**, 몸 약간 앞으로 | 학생, 안경남 |
| 축하·성취 | **하이파이브** 위로 뻗은 팔 + 노란 반짝 선 3개 | 그룹컷 |
| 서비스·친절 | 트레이 들고 눈 감은 활짝 웃음 | 바리스타 |
| 대기·준비 | 의자에 앉아 무릎 위 주먹, 입 벌린 미소 | 취준생 |
| 이동 | 탑뷰로 걷는 뒷모습 + 보라색 **발자국 점선** | 참여 방법 STEP 장식 |

## 9. 장면 구성 규칙 (히어로) [관찰]

1. 흰/라벤더 **아이소메트릭 블록 길**(보드게임 판처럼) 위에 캐릭터를 단계별로 배치
2. 블록 옆면에 단계 라벨(취업준비 / 수능공부 / 중간고사 / 아르바이트 / 자격증) — 블록 색: 바이올렛 `#7F46F1`, 마젠타 `#D86FCC`, 옐로 `#F5B800`
3. 각 캐릭터 옆에 **상징 소품 1개**(책 더미, 서류가방, 칠판 메뉴판, 학사모+장미+졸업장)
4. 시작점에 **삼성월렛 머니·포인트 카드 + P 코인 탑**
5. 원경: 흐린 나무·벤치(피사계 심도), 배경 그라데이션 크림 → 핑크
